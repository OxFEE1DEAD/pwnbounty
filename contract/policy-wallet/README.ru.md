# Кошелёк с принудительной политикой

Отдельный контракт для testnet-демонстрации function-call key. Это не TEE и не замена verifier. Политика получателей и суммы фиксируется при `new` и не меняется методами контракта.

1. Развернуть WASM на отдельном testnet-аккаунте; аккаунт заранее оплачивает хранение кода и начального состояния.
2. Вызвать `new({allowed_recipients:[...],max_transfer:"..."})`, затем `fund` с депозитом для платежей.
3. Добавить на этот же аккаунт function-call key, ограниченный `receiver_id` этого аккаунта и единственным методом `pay`. Передать агенту только этот ключ. Ограничение allowance ключа относится к расходам газа; сумму переводов ограничивает контракт.
4. Агент вызывает `pay` с нулевым attached deposit: `request_id` (32 случайных байта hex), `recipient`, `amount` (yoctoNEAR строкой). Запрещённый получатель или сумма отвергаются до перевода.
5. Через `get_payment` проверить результат callback. `Pending` ещё не означает выплату; окончательное состояние — `Paid` или `Failed`. Повтор тех же параметров идемпотентен; `Failed` можно повторить.

Метод `pay` приватный: прямой чужой аккаунт не может вызвать его. Транзакция через function-call key самого wallet-аккаунта имеет нужный predecessor. Full-access ключ оператора всё ещё может заменить контракт; исключение такого полномочия — отдельный проверяемый шаг deployment. Удаление ключей автоматически не выполняется.

На новый request резервируется 0.005 NEAR из funded budget для хранения записи. Лимит 1024 записей; очистка, возврат storage reserve и вывод остатка в этом демонстрационном контракте отсутствуют. Не использовать для реальных денег.

Сборка из этой директории:

```sh
cargo build --target wasm32-unknown-unknown --release
```

`cargo test --locked` выполняет 4 native unit-теста: отказ по получателю и лимиту, резервирование средств с идемпотентным replay, возврат бюджета после неудачного callback и повтор. `cargo build --locked --target wasm32-unknown-unknown --release` собирает WASM. Реальный testnet-прогон и настройка ключа ещё необходимы.
